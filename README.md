## **Sleet-cpp**

A C++23 UI framework utilizing the Elm-architecture.

</div>

## Dependencies
Sleet-cpp depends on [SDL3](https://wiki.libsdl.org/SDL3/), [SDL3_ttf](https://wiki.libsdl.org/SDL3_ttf/), and [SDL3_image](https://wiki.libsdl.org/SDL3_image/), which are used for rendering, text handling, and other shenanigans a UI framework needs to do.
